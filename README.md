遊戲內容(功能)

1.點擊左鍵：讓 Flappy Bird 獲得向上飛行的動力。

2.未點擊 :Flappy Bird 會因重力影響下墜。

3.遊戲結束：當 Flappy Bird 撞到水管時，遊戲結束。

4.重新開始：遊戲結束後，按滑鼠右鍵重新開始遊戲。

5.得分方式：每當 Flappy Bird 穿越一對水管，即可獲得一分。

6.暫停/繼續：點擊螢幕右上角的按鈕（滑鼠右鍵）即可暫停或繼續遊戲。
